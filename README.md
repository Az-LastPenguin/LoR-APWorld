# LoR APWorld
This is the .apworld of the [Library of Ruina Archipelago Randomizer](https://github.com/Az-LastPenguin/LORAP/tree/main).
[LORAP Setup Guide](https://az-lastpenguin.github.io/guide)

# Features
## Reception Tree Randomization
The order in which you complete receptions can be randomized.

## Book Requirements Randomization
The books which are required for receptions & abnormalities/realizations can be randomized


# Versioning
I use [SemVer 2.0.0](https://semver.org) as a guideline:

X.Y.Z where
- X is major version which is only incremented when something big is added/changed which breaks everything.
- Y is the minor version which is only incremented when something not that big is added/changed which doesn't break anything.
- X is the patch version which is incremented when really small fixes/updates are made.

Testing versions which are versions i'm not yet releasing fully but want them to be tested will look like:

X.Y.Z-W where W is name of a greek alphabet letter, for example: 1.0.0-gamma. Next letter is picked when something has changed in the testing version.
